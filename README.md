# Project Name: Customer Segmentation Analysis
•	Data Extracted was from a Uk based online store which sells mainly occasion gifts. The aim of the study is to help business to better understand its customers so able to conduct customer centric marketing more efficiently. 
•	Software application used: R Programming 
•	Identify which cluster is the most valuable customer based on RFM value and so to better target and market during seasonal sales. Compare the performance of the two models' suitability.
•	Data Wrangling was performed to the required variables for analysed.
•	Statistical Analysis: RFM Feature Engineering & K-Means Clustering was performed to find the optimal no of cluster that was has most valuable customer based. This is particularly useful for marketing team so that we are able to further utilise the data information to further do targeted marketing and improve sales profit.
•	Learning Outcome:
Through this project, I gained hands-on experience using K-Means clustering to segment high-value customers. The project highlighted how customer segmentation can inform targeted marketing strategies to increase retail sales and profits. I also developed skills in R programming for data wrangling and statistical analysis, crucial for effective marketing decision-making.
